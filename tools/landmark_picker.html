Landmark Picker

Click the same named spots on the golden image and on every test image. The result is a landmarks.json that evaluate.py reads directly. Your images stay on this computer.

Setup

Every other loaded image is a test image. Load several at once (Ctrl+A in the file dialog).

Point names

nameGT

Click a name to make it active. Double-click to rename. Removing a name removes its points from every image.

Test images

× removes an image and its points. To remove the golden image, choose another golden first. Starting on another part: save landmarks.json, then Start new part.

Export

Save the file (or paste the copied text into a new file named landmarks.json), then arrange the folder like this:
